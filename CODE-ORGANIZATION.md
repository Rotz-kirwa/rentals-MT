# My Nyumba Code Organization Standard

This project uses a consistent layout to make debugging and future changes easier.

## PHP
1. File/page description comment
2. Authentication & session
3. Page configuration
4. Database/data and form processing
5. Page content
6. Footer & scripts

## HTML
Within page content, keep this order where applicable:
1. Page title
2. Summary/statistics
3. Filters/search/actions
4. Main content/table
5. Modals

## CSS
Keep sections in this order where applicable:
1. Root variables
2. Global/reset
3. Typography
4. Header
5. Sidebar
6. Main content
7. Page titles
8. Summary cards
9. Tables
10. Status styles
11. Forms
12. Buttons
13. Modals
14. Responsive

## JavaScript
Keep sections in this order where applicable:
1. Global variables
2. Document ready/init
3. Table functions
4. Form functions
5. Modal functions
6. AJAX/API functions
7. Utility functions

Vendor files are intentionally not reformatted.
